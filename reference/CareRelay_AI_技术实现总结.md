# CareRelay AI 家庭照护交接助手技术实现总结

## 1. 项目定位

CareRelay AI 面向家庭照护交接场景，解决老人、宝宝、宠物等受监护对象在多监护人轮换照护时的信息遗漏、任务不清、风险难追踪和家属沟通成本高的问题。系统支持文本、语音、图片三种输入，把零散照护记录整理为今日交接卡、待确认清单、下一步待办、风险雷达、家人群消息、语音播报和可视化信息图。

## 2. 当前已完成的技术实现

当前 Demo 采用 `FastAPI + vanilla HTML/CSS/JS + Python Agent Pipeline + SQLite Memory` 的轻量架构，不依赖 Node 构建链，方便在远程服务器上快速部署和复现。

已完成能力包括：

- 三模态输入：文本输入、浏览器麦克风录音/音频上传、图片上传。
- 语音转写：录音后自动转写为文本并进入统一解析链路。
- 图片理解：面向药盒、处方、复诊单、聊天截图、护理记录等图片抽取照护要点。
- 结构化交接卡：输出健康指数、今日摘要、情感状态、必须确认、下一步、已完成、时间线和风险雷达。
- 信息图生成：交接卡先返回，`VisualAgent` 异步生成信息图，减少用户等待。
- 个性化知识库：按监护对象隔离记忆，支持保存、检索和删除。
- 远程演示友好：提供启动脚本、模型 smoke test、离线 fallback 和本地备用图。

## 3. Agent Pipeline 架构特色

当前系统已经搭建了有效的多 Agent Pipeline：

1. `AudioAgent`：负责语音转写，将口述照护信息转为文本。
2. `VisionAgent`：负责图片内容理解，抽取处方、复诊、药物、异常和待办。
3. `MemoryAgent`：负责个人知识库检索，按监护对象召回个性化偏好和历史事项。
4. `FusionAgent`：融合文本、语音、图片和记忆，形成统一上下文。
5. `AnalysisAgent`：使用高质量语言模型生成结构化交接卡。
6. `SafetyAgent`：注入医疗安全边界，避免诊断、剂量调整和不安全建议。
7. `VisualAgent`：使用图像生成模型生成生动清晰的交接信息图。
8. `InteractionAgent`：生成追问、确认事项、家人群消息和语音播报文案。

这一架构的优势在于将不同模态、不同任务和不同风险控制拆分到独立节点，每个节点可以独立替换模型、调整 prompt、设置 fallback。相比单次聊天式调用，Pipeline 更适合黑客松 Demo 现场展示，也更利于后续演进为生产级系统。

## 4. 模型调用与鲁棒性设计

系统对文本分析、图片理解、语音转写、图像生成、向量检索分别配置模型和 fallback。后端统一封装 API Client，并忽略服务器中不稳定的本地代理环境变量，避免外部代理导致模型请求失败。

鲁棒性策略包括：

- 模型调用设置超时，避免单个强模型长时间阻塞。
- 高质量模型优先，快速模型兜底。
- 交接卡与信息图解耦，先返回核心结构化结果，再异步生成图片。
- JSON 解析失败时自动尝试提取 JSON 对象。
- 外部模型不可用时使用本地结构化规则和离线样例保证界面可演示。

## 5. 个人知识库设计

当前知识库使用 SQLite 本地存储，记录监护对象、用户、记忆文本、标签、向量和历史交接记录。系统使用 embedding 生成记忆向量，并通过余弦相似度召回相关记忆。

示例场景：

- 爷爷复诊前总要准备医保卡和病历本。
- 宝宝睡前需要拍嗝并记录最后一次喝奶时间。
- 小猫复查前需要准备航空箱和既往病历。

这些记忆会影响后续交接卡生成，使输出更贴合具体家庭和具体监护对象。

## 6. 后续：模型后训练方向

后续会实现模型后训练，目标是训练垂直领域专项化模型。计划基于家庭照护交接数据、护理记录、处方说明、复诊材料、家属沟通文本和多模态解析结果构造训练集，重点提升以下能力：

- 照护事件抽取：识别时间、动作、对象、负责人、完成状态。
- 任务拆解：把自然语言拆成已完成、待确认、今日待办、明日提醒和长期关注。
- 风险识别：识别药物、异常症状、复诊遗漏、沟通缺口等风险。
- 安全表达：对医疗相关内容保持保守表达，避免诊断和剂量建议。
- 家属可读性：生成清晰、温和、可执行的交接文本。

模型后训练将让系统从通用大模型能力，进一步专项化为家庭照护交接领域模型。

## 7. 后续：知识图谱技术特色

后续会构建家庭照护知识图谱，用于为模型推理拓充辅助语义信息。知识图谱中的节点可包括：

- 监护对象：老人、宝宝、宠物及其个性化偏好。
- 照护事件：服药、进食、睡眠、洗澡、测量、复诊、异常观察。
- 药物与处方：药物名称、服用时间、剂量原文、注意事项、医嘱来源。
- 症状与风险：血压偏高、发热、哭闹、呕吐、精神状态变化。
- 家庭成员：主要监护人、现负责监护人、交接监护人、紧急联系人。
- 时间关系：今日、今晚、明天、复诊前、连续观察周期。

知识图谱可以支持：

- 多跳推理：例如“血压偏高 + 明日复诊 + 缺少具体数值”推导出“补充血压记录”。
- 个性化召回：根据对象和历史习惯补全任务提醒。
- 风险解释：让模型说明为什么某个事项需要确认。
- 可追踪交接：将家庭照护事件沉淀为长期可查询的结构化资产。

## 8. 当前可演示亮点

- 第一屏即为可操作产品界面，而不是普通聊天框。
- 文本、语音、图片输入统一进入 Agent Pipeline。
- 输出包含文字分析、情感分析、Todo List、风险雷达、信息图、家人群消息和语音播报。
- 支持老人、宝宝、宠物三类样例，并能按监护对象维护独立知识库。
- 信息图异步生成，交接卡优先返回，演示体验更顺滑。
- 医疗安全边界贯穿后端 Pipeline。

## 9. 总结

CareRelay AI 当前版本已经完成从三模态输入到结构化交接输出的闭环 Demo，并搭建了可扩展的 Agent Pipeline、个人知识库和多模型 fallback 框架。后续通过垂直领域模型后训练和家庭照护知识图谱，可以进一步提升模型在照护交接场景中的准确性、个性化、推理深度和安全性。
